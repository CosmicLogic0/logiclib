# LogicLib changelog

## 0.1.0 (Minecraft 1.21.1, Forge + NeoForge)
- First version.
- Platform helpers: loader name, mod checks, config folder, client check.
- LogicConfig: simple JSON config files that add new fields automatically.
- CreatorServer: adds Logic Survival to the server list once across all CosmicLogic mods (shared marker `config/cosmiclogic/creator_server.json`).
- LogicRegistry: one way to register items/blocks/etc. on Forge and NeoForge.
